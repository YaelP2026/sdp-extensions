# sdp-extensions
This is a collection of UI extensions (external actions) for SDP/SDM (ValueEdge/ALM Octane).

These extensions have been validated in our environment and work well with our data. However, they are not part of our officially supported product features and should be treated like other marketplace plugins.

Each extension includes:
1. A README file
2. The ZIP file ready to upload
3. A folder with the full extension code
