# sdp-extensions
This is a collection of UI extensions (external actions) for OpenText SDP/SDM (ValueEdge/ALM Octane).

These extensions have been validated in our environment and work well with our data. However, they are not part of the officially supported product features, are not actively maintained, and compatibility with future versions is not guaranteed.

Each extension includes:

1. A README file
2. A ZIP file ready for upload
3. A folder containing the full extension code
